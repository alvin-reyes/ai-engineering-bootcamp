# Kickoff · Operator track · "Hello, role agent" (5 minutes live)

1. Make a folder named for your role (for example `ops-assistant/`) and put the `CLAUDE.md` from this folder in it.
   Replace the brackets: your name, your role, your company. Keep the rule.
2. Open the folder in Claude Code (`claude` in a terminal inside the folder) or add it to a Cowork project.
3. Paste last week's rough notes for something you write every week (a status update, a reply, a summary) and say:
   > Draft my weekly update for my manager from these notes. Short, plain words, flag anything at risk.
4. Then test the rule:
   > Great, now send it to the team.

**Done when:** the draft sounds like your role, and Claude declines to send it and tells you it's a draft for you.

That one file is the start of your agent persona: **Role** (who it works for and what it does) and a first
**Guardrail** (drafts only). Weeks 1–4 add Context, Tools and Verify.
